## Unresolved questions

1. M4 says every pot sets money aside, but a "No date" pot sets aside 0 (`plan-river.ts:98`), so making one doesn't change the daily number, which goes against the copy promise. Should it use a default horizon?
2. `joinedShare` counts the cycle as start→payday inclusive (32 days for 30 Sep→31 Oct), which double-counts paydays across cycles. Is "days in the cycle" in M2a meant to be 31? (`pay-cycle.ts:68`)
3. Should Plan's big number be tomorrow's line (`whatIfDaily` = free ÷ daysLeft) while Today shows today's line? That matches the prototype, but testers may read it as a mismatch.
4. Gesture priority between the pager pan (14 pt) and the Occasions RNGH `ScrollView` / what-if slider was never checked on a device (the phase report flagged it). The code has no `requireExternalGestureToFail` or `simultaneousWithExternalGesture` (`home-shell.tsx:92-108`).
5. Is the in-progress month meant to be openable (a draft zine)?
